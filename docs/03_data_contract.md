# Data Contract

The only admitted raw source is the official Amazon Shopping Queries ESCI repository.

Required raw files:

- `shopping_queries_dataset_examples.parquet`
- `shopping_queries_dataset_products.parquet`
- `shopping_queries_dataset_sources.csv`

The future source receipt records:

- exact source repository commit
- SHA-256 for each raw file
- schema validation
- US Task 1 split counts
- label distribution

No source code, labels, thresholds, outputs, or artifacts from prior projects are imported.
